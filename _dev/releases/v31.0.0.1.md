# v31.0.0.1 — cuenta y perfil

Acceso después de INICIAR, antes de las guías: continuar con Google o sin cuenta, opción confirmada por el propietario. Supabase Auth con SDK oficial local 2.118.0, OAuth PKCE, persistSession/autoRefresh y retorno al sitio de Pages. La sesión válida evita repetir el panel en ese navegador. No hay invalidación de otros dispositivos al acceder desde uno nuevo; borrar datos del navegador, revocar o cerrar sesión obliga a identificarse otra vez.

Botón cuadrado de perfil a la izquierda de V/D, exclusivo del menú principal. Ventana emergente, app de fondo inert, teclado/foco/Escape. Nick, partidas contabilizadas (victorias + derrotas disponibles), victorias/derrotas y porcentaje, FS, Elo/rango/división, colección distinta/copias/repetidos, logros conocidos, sobres pendientes, rarezas y situación de Liga e ID local. Los empates históricos no están registrados y no se inventan. Diseño sin desplazamiento interno en siete resoluciones, con compactación para teclado/alturas reducidas y columnas en horizontal.

Primera elección de nick gratuita; otro cambio gratuito cuando se cumple un año desde el anterior. La tabla vive en Supabase; RPC security definer con search_path vacío, auth.uid, SELECT propio bajo RLS y sin escrituras directas. Bloqueo FOR UPDATE para impedir dos cambios simultáneos. Reintentar el mismo nombre no consume un cambio. El caché de lectura está separado por cuenta y nunca habilita cambios offline. Nombres de 3–20 caracteres normalizados NFC; no tienen que ser únicos. No hay cobros ni cambios de pago.

El propietario confirmó que la migración SQL revisada se ejecutó con Success. La primera versión incluía DROP POLICY; se sustituyó por CREATE condicionado para evitar retirar reglas. No borra datos; las pruebas verifican que repetirla conserva una tabla de progreso preexistente y el propio nick/fecha. No se han solicitado ni guardado claves secretas de Google/Supabase. No se despliegan servicios de pago.

Los datos de juego y el respaldo de prelanzamiento permanecen locales. No hay importación a nube, reinicio de estadísticas/saldo, inventario compartido, mercado real ni multijugador añadido en esta entrega. El perfil explica esta distinción. Iniciar/cerrar la cuenta no cambia el progreso local ni mezcla inventarios. El service worker omite todos los orígenes externos para evitar cachear autenticación/perfiles.

Validación: 194 pruebas de la suite, incluidas las simulaciones de pasivas y exclusión de solicitudes de autenticación de la caché. SQL bajo PostgreSQL embebido PGlite 0.3.14 (idempotencia, conservación, RLS, anónimo, permisos, validación, primer nick, plazo anual y reintentos). Chromium/SDK real con endpoints simulados para OAuth y RPC: PKCE, vuelta del proveedor, sesión tras recargar, nick anual, cierre de sesión, invitado, SDK no disponible y RPC no disponible. Siete resoluciones: 320×480, 320×568, 393×350, 360×640, 393×851, 851×393, 1280×851. Guías de 19+20 pasos en cuatro resoluciones, orden y ausencia de cambios de perfil/Liga. Actualización PWA v30.2.61 → v31.0.0.1 y uso offline del acceso invitado, perfil y guía. Inicio aleatorio y animación oculta conservados. Las notas públicas no revelan el logro oculto.
