# Correcciones acumuladas — misma v31.0.1.4

La proyección de combate remoto creaba un objeto G nuevo en cada respuesta. El
controlador de audio interpretaba cada actualización como una partida distinta y
recreaba las dos pistas. Ahora se conserva la identidad del objeto mientras el ID
de partida sea el mismo, actualizando sus campos. Una partida nueva sí recibe otro
objeto. Se mantiene la selección solo cuando la revisión no cambia. No se alteran
las reglas, las pistas musicales ni el servidor.

Se amplían las novedades de v31.0.1.1 a v31.0.1.4 con sus correcciones acumuladas.
El archivo de referencia _dev/changelog/published-v31.0.1.x.json recoge únicamente
notas de commits publicados. La prueba de retención exige conservar cada párrafo
publicado en su versión original; una nota de temporada de una preparación de
v31.0.1.2 se atribuye a v31.0.1.3, donde llegó a publicarse. Las versiones anteriores
no cambian. Se mantiene la comprobación de confidencialidad de las notas públicas.

El texto de acciones deja de truncarse a dos/tres líneas y utiliza el ancho de la
propia carta para ajustar su tipografía. Se reservan márgenes para el marco y se
muestran nombre, efecto y limitación de uso completos. Los nombres de oradores
pueden ocupar las líneas necesarias en las vistas normales y ampliadas; sus
estadísticas se alejan del marco. La presentación compacta de combate se conserva.
El visor reduce también su ancho con la altura disponible para respetar la
proporción en horizontal. Se conservan las imágenes y las reglas de los cromos.
